#### Este projeto visa prever o futuro baseando-se em dados de treinamento em uma pasta data, a pasta data pode ter arquivos PDF, TXT, CSV, JSON, TOML, YML, YAML, DOC, XLS, XLX, XML, SQL, JL e outras extensões como PNG, JPG, JPEG, GIF e BITMAP

o DEEP LEARNING será feito utilizando algoritmos avançados de CNN e outros que processem imagens, videos e textos
tendo uma página para o treino
e outra página para prever o futuro

## Como usar

1. Execute `cargo run` dentro da pasta `futuro`.
2. Abra `http://127.0.0.1:3000` no navegador.
3. Use `Treino` para enviar arquivos de treinamento.
4. Use `Previsão` para enviar arquivos de previsão.

Os uploads são salvos em `data/train/` e `data/predict/`.
